## What's new

Textus 2.0.0 runs on a new desktop core written in Go with MyGo instead of Rust and Tauri, and brings a file tree that works like VS Code's, windows that reopen where you left them, an interface font of your own, and plugins that work as soon as they are switched on.

### New

- **Settings › Appearance › Interface font** sets the font of Textus's own text - the start page, menus, panels and Settings - apart from the document's text font. It changes everything at once, and **System's** goes back to the system font.
- Cut, Copy and Paste files in the file tree, with the keys or from the right-click menu: a paste goes into the selected folder, or the folder of the selected file. Cut moves them, and links follow as for a drag; a cut file stays faded until it is pasted. Duplicate (⌘D or Ctrl+D) makes a copy beside the original, named as Finder names one: "plan copy.md", then "plan copy 2.md", in the language Textus is set to. Hold ⌥ (Ctrl on Windows and Linux) while dragging in the file tree to copy instead of move.
- When a file or folder of the same name is already where you move, paste or copy to, the file tree asks: Replace (the one there goes to the Trash), Keep Both (the new one is numbered), or Cancel. Every copy, paste and replace can be undone.
- Edit › Undo takes back what you did in the file tree: a move, a rename, a new document or folder, and a move to the Trash, which puts the item back where it was. Edit › Redo does it again. Links that were updated by a move or a rename go back too. The notice after a move or a delete also has an Undo button. Nothing is undone if the item has changed since, is gone from the Trash, or something else now has its old place; Textus tells you which.
- The file tree works from the keyboard: F2 renames the row in place, as does Return on a Mac (⌘↓ opens it there; Enter opens it on Windows and Linux). ⌘⌫ on a Mac, or Delete, moves to the Trash. Shift with an arrow picks a range, and ⌘A or Ctrl+A picks every row, including those of a large folder not shown yet. Typing a name goes to the row that starts with it, in the tree and in the outline.
- Collapse All folds every folder in the file tree: from the tree's Sort menu, the right-click menu of its blank area, or ⌘← (Ctrl+← on Windows and Linux), as in VS Code. The menus show the shortcut beside it.
- **Settings › Editor › Press Enter twice to leave a code block**: turned off, Enter in a code block always adds a line; press Down on the last line, or Cmd+Enter (Ctrl+Enter), to leave it.
- For plugin authors (plugin API 1.11): `contributes.completions` with `where: "code"` offers completions as you type in a code block, told the block's language, and `contributes.textFiles` opens a file type as plain text to edit in the source editor, coloured as a code language. The new TeX plugin uses it for LaTeX and BibTeX files.

### Improved

- Textus's desktop core - files and folders, windows and menus, the tray, Textus AI's requests, export, updates and the `textus` command - is rewritten in Go on MyGo, in place of Rust on Tauri. It keeps its settings, plugins and data where 1.x kept them, so they carry over.
- Textus AI, Word import and `textus read` read PDF, Word, PowerPoint, Excel (`.xlsx`, `.xlsm`, `.xls`, `.xlsb`), OpenDocument spreadsheet, EPUB, RTF and HTML files as Markdown, with readers built into the new core.
- Plugins work as soon as they are switched on: Textus no longer asks for each permission when you turn one on, before it uses your AI model, or before it connects to a server over SSH, and a plugin's page no longer lists permissions to revoke. Whatever it lists, a plugin still can't read Textus's own settings or the secrets it keeps.
- Settings lists the Textus AI pages after Editing, Extensions and Shortcuts, and the Plugins page leads with **Install from file…**; making a plugin with Textus AI is in its menu.
- A Git plugin commits in a repository with hooks without asking you to trust the repository first; the hooks run as with your own git. A repository whose settings name programs to run is still asked about once.
- Textus AI's standing instructions are about 40% shorter, with the same rules, so every request sends less.
- The file tree updates by itself when files change on disk, from Git, a sync service or another app, without switching away and back.
- While you scroll the file tree, the folder's name and its buttons stay at the top, and under them the row of each folder you are scrolling through, so you always see where you are. Click such a row to fold its folder.
- Dragging files onto the file tree, from Finder, File Explorer or the tree itself, now lights the whole folder they will go into, its row and every row inside it, so you can see which folder a drop lands in. A folded folder opens when you hold the pointer on it for a moment.
- Files dropped onto the file tree from Finder or File Explorer can be taken back: choose Undo on the notice, or Edit › Undo while the file tree is in use, and the copies go to the Trash. Files that were already in the folder are never touched, and nothing is undone if a copy has changed since.
- Renaming in the file tree, and naming a new document or folder, happens in the row itself instead of in a dialog, with the name selected without its extension. A name already taken is said right below it, so you can type another; Esc gives up.
- The file tree's New File and New Folder buttons create the item in the folder you last clicked, or in the folder of the file you last clicked, instead of always at the top. A slash in the name creates the folders on the way: `2026/March/plan` makes the folders `2026` and `March` and the document `plan.md` in them.
- The right-click menu of several selected files and folders has Cut, Copy, Duplicate and Copy Path besides Open and Move to Trash.
- The question before moving files to the Trash has a **Don't ask again** box; **Settings › General** turns the question back on.
- Rows you picked in the file tree turn quieter while you work elsewhere, and come back when you return to the tree.
- A sidebar panel with nothing to show says why, in the list's own text, with the buttons to begin: an empty file tree offers New File, Open… and Open Folder…, Search offers Open Folder…, and the outline tells "No document is open" from "This document has no headings yet".
- While the file tree follows the open document instead of an opened folder, its **Open This Folder** button stays in sight.
- A document opened from Finder or File Explorer, a second launch or Open Recent goes to the window that already has it open, else to the window whose folder holds it, else to the window in front.

### Fixed

- Quitting Textus ends it. **Quit** in the macOS Dock or app switcher no longer closes the windows and leaves Textus running, the tray icon goes with the app instead of staying in the Windows notification area, and `textus commands run quit` quits without opening a window first.
- Closing the last window with **Keep running in the background** off ends Textus, also while a plugin's background job or floating view is open.
- When Textus quits, a window with unsaved changes comes to the front with its question instead of holding up the quit unseen.
- Checking for updates, or **Back to stable**, while no stable release is published says there is none, instead of failing with "the update server answered 404 Not Found".
- Textus opens at the size and place you left it, also when the window filled the screen or was maximized or in full screen: it opens that way again. With **Settings › General › On launch, open › Last documents**, each window comes back where it was. A window left on a screen that is no longer connected opens on the main screen, no bigger than it. (#795)
- The first time Textus opens, its window is 1200 × 800, or the size of a smaller screen, centred, instead of 800 × 600. (#795)
- With the same folder open in two windows, saving a document in one now updates the other window's file tree too, such as its order when sorted by date modified.
- In a code block on a Mac, Cmd+Right stops at the end of the line instead of jumping to the start of the next one, and Cmd+Up and Cmd+Down go to the block's first and last line; pressed again, to the document's.
- On a Mac, Home and End move to the start and end of the line, instead of putting a box character into a code block.
- A text file that isn't a document (`.tex`, `.bib`, `.yaml`) shows as its own text, coloured as its language, instead of being read as Markdown with its lines run together.
- A diagram, formula or HTML block first in a document is drawn when the document opens. The caret the document opened with sat inside it, so only its source showed; now nothing shows as source until you press a key, click or touch, and the first key shows the source before typing into it.
- A wide entity-relationship diagram, flowchart or class diagram shrinks to fit the column instead of being cut off at the side. A timeline, Gantt chart, git graph or user journey keeps its smallest readable scale and scrolls, past front matter and `%%{init}%%` directives too; the zoom button still shows any diagram full size.
- Remote pictures from image hosts that guard against hotlinking, as several Chinese image CDNs do, load instead of being refused with 403: Textus now asks for them with an empty referrer, as other editors do.
- Installing a plugin no longer fails with "answered 302 Found" when the download is redirected from `textus.md` to `textus.catvinci.com`. A download or catalog error now says where the answer came from, where a stopped redirect points and which proxy was in effect, so a proxy that intercepts the request shows in the message.
- A picture after a list item's text, wide enough to wrap to a line of its own, no longer leaves a large gap above the item on macOS. (#815)
- The AI's notes and counts in the margin and the chat's count badges are set in the interface font, the one picked in **Settings › Appearance**, instead of a generic one or the document's.
- The diagram viewer's buttons and hint, and a plugin block's source button, take the theme's text colours. A web page's address is a field like every other: a rounded rectangle, ringed in the accent while typed in. A plugin's page and the plugin catalog go back with the app's own arrow.

### Platform notes

- **macOS:** Textus now needs macOS 13 (Ventura) or later; on macOS 11 and 12, keep the version you have.
- **macOS:** the app is signed ad hoc and not notarized, so macOS asks before it opens the first time; if it refuses, choose **Open Anyway** in **System Settings › Privacy & Security**.
- **Windows:** the portable zip is no longer built; install Textus with the installer. A Textus installed with an earlier installer (`Textus_1.4.7_x64-setup.exe` and before) isn't replaced: 2.0.0 goes in `%LOCALAPPDATA%\Programs\Textus` beside it, and the old one can be uninstalled in **Settings › Apps**.
- **Linux:** the AppImage is replaced by an archive that install.sh installs in your home folder, where Textus updates itself (`curl -fsSL https://github.com/atoz03/Textus/releases/latest/download/install.sh | sh`); the `.deb` and `.rpm` install it in `/opt/textus`, and for those you download each new version yourself.
- **Linux:** with Wayland, windows open at their last size; Wayland doesn't let an app choose where its window goes.
- Of the versions before 2.0.0, only the 1.4.7-rc.4 test build published here updates to it by itself; from Textus 1.4.7 or any other earlier version, install 2.0.0 from the files below.
- Textus AI and `textus read` can't read a PDF encrypted with AES-256, which 1.4.7 and earlier could.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.
